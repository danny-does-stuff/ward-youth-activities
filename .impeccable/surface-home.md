# Home — This week

Visitor mode: Operate

Audience: Celina Ward parents on a phone. Job: see this week’s youth events, then add one or file it on a calendar.

## Direction contract

THESIS: The kitchen fridge is the schedule — days as stacked pad blocks, events as marker lines — not a feed of identical cards.

OWN-WORLD: Enamel off-white, magnet red, marker blue, sticky yellow; dark enamel when the phone is dark. Ruled lines, magnet bar, fat marker CTA. Display in a marker hand; body in a clear workhorse sans.

STORY: You open it and already know what happens this week. You tap a line for place and calendar. You post with the yellow marker button.

FIRST VIEWPORT: Magnet bar with Celina Ward. “This week” as the pad title. Day blocks stacked (SATURDAY then events on ruled lines). Compact row: time, title, youth. Add event is a fat sticky-yellow control in thumb reach. Empty week shows the pad with one invitation to add the first event.

FORM: Fridge Calendar, rank 1 on the grounded list, Impeccable’s pick (not the roll). Seed key c66c702d.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Signature interaction: tap a ruled line and it peels open like a note — details, add to calendar, add youth — then presses flat again.
